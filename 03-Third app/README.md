# Perfect Number Problem

## Problem
Write a program to check if a number is **Perfect** or not.

> **Note:**  
> A Perfect Number = Sum of all its proper divisors (excluding the number itself).

## Examples
- 28 = 1 + 2 + 4 + 7 + 14  
- 6 = 1 + 2 + 3  

## Input
28
12

## Output
28 is perfect.
12 is not perfect.
